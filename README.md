# 🛒 E-Commerce Sales Analysis Dashboard

## 📊 Project Overview

This project analyzes e-commerce sales data to understand sales performance, profitability, customer behavior, product performance, and regional trends.

An interactive dashboard was created using **Power BI**, with data preparation and analysis performed using **Excel and Power Query**.

## 🛠️ Tools & Technologies

* **Power BI** – Dashboard & data visualization
* **DAX** – Calculated measures and KPIs
* **Power Query** – Data cleaning and transformation
* **Microsoft Excel** – Data preparation and analysis

## 📌 Key KPIs

| KPI                 |     Result |
| ------------------- | ---------: |
| Total Sales         |   ₹2.74 Cr |
| Total Profit        |   ₹84.72 L |
| Profit Margin       |     30.90% |
| Average Order Value | ₹27,418.25 |

## 🔍 Key Analysis

The dashboard provides analysis of:

* Sales and profit by category
* Sales and profit by region/state
* Monthly sales trends
* Customer performance
* Product performance
* Payment mode analysis
* Profit margin by category
* Top-performing customers and products

## 💡 Key Insights

* **Electronics** generated the highest sales.
* **Delhi** recorded the highest profit among states.
* **Priya** was the highest-spending customer.
* **December** recorded the highest monthly sales.
* **Headphones** generated the highest product profit.
* **Net Banking** was the most-used payment mode.
* Overall profit margin was approximately **30.90%**.
